# Block font sizes

Use with an S3 scalable built-in or SD TTF font. Headings descend in size; body paragraphs restore the reader size. Check inherited em/percent sizes, root-relative rem, reader-relative px/pt, heading overrides, and 8-44 pt bounds. Change reader size, reopen cached pages, select heading words, and compare portrait/landscape. Bitmap fonts and Light mode retain uniform sizes. Inline and table-cell sizing are outside this fixture.

Package the source files with `mimetype` first and uncompressed; all paths are relative to this folder. The packaged fixture is `test/epubs/test_block_font_sizes.epub`.
